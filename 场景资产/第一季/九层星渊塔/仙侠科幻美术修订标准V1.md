# 古旧基底适度提质｜美术修订标准 V1

日期：2026-10-18。此文件是美术规范，交接仍仅使用 `文档/项目总控与交接.md`。

## 当前有效方向

用户先指出素材过于破旧，要求参考抖音AI漫剧《大天蓬》，包括场景；随后明确“也不要太仙侠太花颜色”，最终要求：“场景也不要太仙侠，颜色不能太花里胡骚，基于我们之前的古旧稍微提升一点就行”。最后这条是本次修订的有效尺度。

保留原来古旧、厚重、神秘的上古星际设施，只适度改善材质、光影、工艺细节和画面可读性。此前助手提出的华美仙宫、玉石金饰与通透晶体大幅调整超过要求，已撤销为正式方向；期间生成的候选原图仍归档，明确标注未采用，不覆盖已认可定妆和场景基底。

| 项目 | 本次执行 |
|---|---|
| 造型 | 保持原建筑轮廓、桥路、石阶、环轨和行动布局；不额外增加装饰天宫、飞檐 |
| 色彩 | 青黑、石灰、暗铜等低饱和主色，局部原有暖灯及必要冷色能量，不添多色光污染 |
| 材质 | 保留石纹、岁月感与铜包浆；稍减过密碎裂、泥污和重锈，让雕纹、接缝、金属边缘可辨 |
| 光线 | 原光向与冷暖逻辑不变，黑位有层次，亮部受控，远近景清楚 |
| 仙侠/科幻 | 仙侠人物与上古星际机制继续成立，场景保持古旧神秘；不做华丽天宫翻新 |
| 人物 | 原脸、原服装款式和已发生的局部战损连续；改善肤质、绣纹和纱层，不自动修伤或全身加脏破 |
| 高清 | 记录真实原始像素与SHA，不把放大或高饱和算作提质 |
