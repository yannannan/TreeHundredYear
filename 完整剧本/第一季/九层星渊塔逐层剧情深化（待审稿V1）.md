## 一、全季最重要的故事问题

**核心主题：永生不等于有能力保护所有人。真正的爱既包括守护，也包括尊重对方的决定。**

**外部悬念：** 为什么修仙世界的塔会出现星际结构？这座九层星渊塔到底在选拔破关者，还是在挑选愿意承担代价的人？

**内部悬念：** 周辰和苏晚为何会本源共生？两人此前的300年生命中，究竟缺失了哪些时间与记忆？其关键答案可以在第一季收束一部分，但不得靠临场强加无伏笔设定。

**人物冲突：** 周辰出于活得太久而习惯“一个人扛下一切”；苏晚不愿被他以“保护”为名排除在决定之外。前期这种冲突会制造自然幽默，中期会造成真实损失，终局应当让两人的选择具有明确的**自主性**。

**开场外部危机（候选）：** 塔外一座城的时间出现不规律错位：晨钟未响，人已见到暮色；同一人的脚印先于人出现。周辰追查星渊塔与两人的共同本源，苏晚为寻找一批失踪者及时间错位原因进入塔的范围。二人目标并不完全相同，被迫合作。该具体事件是编剧候选，并非用户已批准。

**核心推进公式（每一层不可缺一）：** 视觉奇观与规则亮相 → 主角依据旧经验误判 → 代价真实发生 → 争论与调整 → 以人物成长换取破局 → 带走永久状态和未来伏笔。

## 二、九层逐层故事方案

### 第一层｜逆重天阶（候选名称）
**视觉卖点：** 一座悬在云海与深渊间的古老石阶群，星际金属巨环从塔身贯穿，远处上下颠倒的瀑布与落石同步运动；光影方向稳定，唯重力轴变化。
- **入场动机：** 两人追随同一条时空异常线索踏入首层；对方不愿让另一人掌握自己的本源秘密，互相挤兑。
- **显性规则：** 在特定机关范围内，每次主动释放法术，局部重力轴会按固定顺序转动90度；机关鸣响后有短暂稳定期。**不主动施法**不会引发下一次切换；自然坠落仍遵循当前重力。
- **错误尝试与代价：** 周辰习惯一剑开道，反使通道向侧面“坠落”，石桥碎裂、苏晚肩部擦伤、周辰所持指路古符被卷入深渊。再生修复伤口，但**古符无法恢复**。
- **反转与破局：** 苏晚用落砂与机械摆钟确定重力切换序列；周辰放弃强招，真实承重托住断桥，两人按时间窗共同跨过；这是合作，不是单人开挂。
- **关系推进：** 苏晚嘲讽他“活了三百年，还是没学会看路”；周辰嘴硬，却第一次照她的安排行动。
- **结尾伏笔：** 塔钟按规则响了九次，稳定后又出现极轻的第十次回响（候选线索）。
- **制作注意：** 高空场景要有远景尺度参照与人物脚部接触点，不在一个镜头中混做重力切换、飞行、爆炸和打斗，适合拆成若干短段。

### 第二层｜双影浮城（候选名称）
**视觉卖点：** 光滑黑石街道、流动星雾、古城檐角与透明光幕重叠，夜色中每个人的影子似乎走在本人前面。
- **入场动机：** 入口留下两条“安全路”，一条通向失踪者的呼救，一条指向与周辰本源相同的光源。
- **显性规则：** 城中的“影子”可展示人物若作出某个选择的一条可能未来，但**并非必然命运**；越相信它，越倾向重复同一选择。镜像会模仿言行，却无法共享本人此刻的触觉反馈。
- **错误尝试与代价：** 周辰看到“苏晚背叛自己”的未来碎片而隐瞒线索，苏晚看到“周辰独自封闭入口”的影像，二人分头行动，误入两处循环街道。
- **反转与破局：** 两人不再靠影像辨认对方，而通过只有两人共同经历过的伤痛/心跳反馈验证眼前人的真实状态；选择不依赖预测的眼下行动，打破镜像自证循环。
- **关系推进：** 两人承认彼此都没有足够理由信任，却答应在找到出口之前不隐瞒风险。
- **结尾伏笔：** 破碎影墙反射出并不属于仙侠时代的现代城市灯光（仅在第一季埋点）。
- **制作注意：** 影像和真人需有清晰材质区分；不能让同一镜头里凭空多出相貌完全相同却无法区分的人物。

### 第三层｜星蚀沙海（候选名称）
**视觉卖点：** 会吞噬灵力的银黑沙漠，沙暴中露出亿万年前的巨型飞船骨架与一抹不合环境的蓝白玄冰结晶。
- **入场动机：** 在沙漠深处发现塔内受困者及尚能提供方位信息的古老装置。
- **显性规则：** 沙粒持续吸收外放灵力，施法越强耗损越快；二人身体能再生，却不能凭再生制造无限物资或替别人重生。保护罩与导航仪共用有限能源。
- **错误尝试与代价：** 周辰准备只护苏晚直冲出口，苏晚坚持返回救人；二人为能源分配争执，耽误时机，沙暴逼近。
- **反转与破局：** 苏晚拆开失效的星舰结构做实体导风廊，周辰仅在最危险片刻使用灵力稳住骨架，留出能量护送受困者；**不是所有人都能完美获救**，至少有一人必须等待下一次通道开启。
- **关系推进：** 周辰承认“能活很久，不代表能补回一次犹豫”；苏晚意识到善意也要承担操作后果。
- **结尾伏笔：** 失踪者留下一片带有玄冰纹样的碎片；关联最终冰封的视觉语言。
- **制作注意：** 主要场景用沙海远景+实体残舰尺度制造震撼，强调风沙真实碰撞与材质声，不把全部沙暴做成无逻辑发光粒子。

### 第四层｜无声律庭（候选名称）
**视觉卖点：** 巨大审判庭悬浮着以金色文字形状组成的誓言锁链；这里的法则像能被看见的语言力场。
- **显性规则：** 试炼会把进入后自愿说出的**确定性承诺**具象成约束；誓言未兑现时，相关动作会遭到力场制止。普通事实陈述和疑问不触发。
- **错误尝试与代价：** 周辰轻率说“我不会让你受一点伤”，导致关键时刻被誓言反噬，无法允许苏晚主动承受可控的风险。
- **冲突：** 苏晚说“我不需要你替我保证人生”；周辰以为她拒绝保护，其实她反对被剥夺选择。
- **反转与破局：** 二人找到誓言的可检验真意：法庭只约束**自己可控制的行为**。周辰更改做法，承认自己无法担保所有结果，转为“我不再替你决定”；苏晚独立承担任务，将审判庭的矛盾暴露给机关。
- **永久代价：** 周辰第一次必须放下“全能守护者”的自我形象；二人的分歧尚未根治。
- **伏笔：** 主角发现“自愿”比力量更容易改变塔内的底层条件，为第九层双人自主拒奖铺垫。
- **对白基调：** 幽默来自“承诺比拔剑危险”而非无意义说教。

### 第五层｜残舰灵墟（候选名称）
**视觉卖点：** 深埋塔腹的坠毁星舰，古仙门像舰船外壳的封条，巨型数据柱与飞船骨架穿插，神性与废墟科技同时可见。
- **显性规则：** 机关识别的是“本源编码+自愿授权”，而非修为强弱。单人强行注入灵力将启动排异机制并擦除一段与本源有关的短时记忆。
- **错误尝试与代价：** 周辰想独自替苏晚承担认证，导致自己短暂失去与前几层某一关键线索相关的记忆。
- **反转与破局：** 苏晚发现认证并非谁更强，而是两人以不同但互补的编码**同时选择合作**，机关才开放记录；记录提示实验本质是“守护时空连续性”的候选线索，真正原始目的仍需后续验证。
- **关系推进：** 苏晚不能替周辰恢复丢失的记忆，只能把他曾经的选择告诉他；他首次主动询问她的判断。
- **伏笔：** 舰载残图出现十处能源节点，但对外公开图只有九处。第十节点功能未在本层直接揭晓。
- **制作注意：** 用人物立于残舰控制核心前的微小尺度对比制造震撼，避免在同一段内同时表现大量不可读的数据文字。

### 第六层｜轮回梦市（候选名称）
**视觉卖点：** 如同古代灯火夜市，市集每盏灯中悬着某人珍贵的回忆；远景灯海像一颗散落于星云的人间星球。
- **显性规则：** 交易出去的记忆当场不可逆地从意识里抹去，买回必须付出**另一份真实且等价的记忆**，不能通过身体再生恢复。
- **错误尝试与代价：** 为找到出口，周辰自愿卖出一段与苏晚共同冒险的回忆；苏晚以为他轻视那段经历，关系发生真正裂痕。
- **反转与破局：** 他虽无法记起共同经历，却在危险里再次做出救她的选择；苏晚意识到“记得爱”和“愿意爱”是两回事。两人拒绝继续以彼此记忆换便利，改为帮助梦市中被遗忘的人建立外部物理记号，破解循环之路。
- **情感节点：** **可以考虑在极少数两人真实和解、相互靠近的浪漫镜头下运用《神话》情绪参考；不是因夜景/星空自动播放。** 是否确实安排这首歌待分集审定。
- **伏笔：** 周辰无意识画出玄冰纹路，说明某些身体反应并不依赖可回忆的记忆。
- **制作注意：** 本层浪漫需要细腻表演与有克制的音乐，减少灯光与镜头炫技，强调眼神和人物主动靠近。

### 第七层｜天机命盘（候选名称）
**视觉卖点：** 规模巨大的环形运算星盘推演无数条命运枝丫，巨大光轨与小小的人物构成反差。
- **显性规则：** 系统给出的“最佳结果”只对它预设的**单一目标函数**有效（例如两人最快离塔），并不是对所有生命、所有未来都最好的选择；屏幕展示的是概率建议，不是铁定预言。
- **错误尝试与代价：** 周辰接受最安全路线，导致一批受困者的出口被暂时关闭；苏晚拒绝听令独自救人，差点被困。
- **反转与破局：** 两人明白不能把责任推给算法：根据路线上每一次可能的损失，亲自承担较难的方案。周辰让苏晚决定行动路线，自己负责兑现她提出的救援步骤。
- **关系推进：** 周辰不再把“我来保护”理解成“我来替你选”，苏晚也不再因为一次错误就否定他全部信任。
- **伏笔：** 命盘推演出现“一人停留，一人被送离”的残缺概率图，画面数字“三百”只作为待解释碎片，不能提前剧透终局全部答案。
- **制作注意：** 只呈现一两条清晰因果分支，不让观众面对一屏不可读的公式。

### 第八层｜众生悬桥（候选名称）
**视觉卖点：** 巨桥贯穿多个浮空世界，每根桥缆连着塔中被困者的生命舱与闪烁光流；一端为耀眼出口，一端是渐暗的人群。
- **显性规则：** 桥梁通行与受困者维持装置共享有限能量；直接通关会压低救援系统的最低保障。周辰/苏晚两人体内的本源可形成同步脉冲，但需要两人**自愿并频率稳定**。
- **错误尝试与代价：** 苏晚想把所有能量留给被困者，周辰想先保证她安全，两种独立正确的善意互相冲突，短暂破坏桥梁稳定。
- **反转与破局：** 他们共同设定可核算的能量分配策略：通过本源脉冲把能量在峰值时暂存于桥体、谷值时支撑生命舱，放弃快速出口而争取有限时间护送。成功只解决**一部分即时危机**，没有全知全能地拯救一切。
- **永久代价：** 两人的本源进入疲惫状态，下一层无法再倚赖强行施法；**第一次可持续稳定的本源共鸣**发生。
- **情感节点：** 两人在大危机后有短暂真实拥抱或握手；是否安排爱情音乐需考虑整季频率，不能让《神话》层层重复。
- **伏笔：** 闪烁的备用能源回路指向第九层奖励区之外的某个闭合系统。

### 第九层｜终焉授印（候选名称）
**视觉卖点：** 巨大圆形授印圣殿，星海被映在古老的玉石地板上；九层胜利印记悬空落下，观众以为结束。
- **显性规则：** 通关者分别获得**真实可兑现的奖励**与安全离塔权利。**奖励与离塔都必须以两位个人的自主同意为依据**；不能因一人替另一人说话而判定同意或拒绝。
- **真实诱惑：** 周辰有机会取回被交易或擦除的片段记忆；苏晚有机会让塔中一部分仍被困的普通人平安脱险，或获得关于本源起源的明确线索（此处奖励内容属候选，后续须定稿以避免同情心与拒奖冲突）。
- **错误认知：** 两人先以为“结束试炼=可以完美解决塔内危机”，却发现奖赏只能处理可计价、可登记的一部分事情；塔的更深层时间异常仍未被解释。
- **主动决定：** 周辰放弃恢复记忆的私利，苏晚放弃可立即领取的回报；**双方各自、知情、自愿**明确说出拒领奖励、拒绝离塔的理由。不是机关诱骗他们选拒绝，也不是两人被迫无法离开。
- **三条件同时满足：** (1)两人活着完成1—9层；(2)第八层形成且仍可维持的双人本源共鸣；(3)本层两人分别明确拒绝奖励和离塔。此时**隐藏第十层才开启**。
- **关键悬念：** 九层授印光环背后出现第十道回响，真正的入口不是新怪物巢穴，而是时空枢纽。
- **必须避免：** 把第九层写成“不能拒绝的假奖励”或强迫离塔，否则人物拒绝将失去自主牺牲的价值。

## 三、隐藏第十层｜时空枢纽（用户锁定机制+候选动机链）

**已锁定不改的事实：** 仅双人共鸣、双人活着完成九层、双方拒奖拒离塔才开启；A关闭枢纽回归原天地，安全生活但永久丧失跨时空能力；B维持枢纽，周辰冰封，苏晚穿越现代，三百年分离代价；最后选择B。第十层**不是打怪升级关**。

### 为何B有吸引力而不是编剧强行逼人赴死？（以下是待审创作方案）
1. **承接前九层：** 第一、二层出现时空错位；三、八层遇见被困者；五、七层发现本源装置和异常预测。观众已看到“真正的问题可能在塔外与跨时空通道之间”，不只关乎周辰/苏晚两个人。
2. **A必须是真实可选择的幸福：** 关闭枢纽后，两人确实能离开并安宁相伴，不发生临时陷阱；但无法再进入时间断层，某些已被困在错位时空中的人会失去通过此枢纽寻回的可能（后果待审，不把A写成隐蔽邪恶选项）。
3. **B守住一种未来的可能：** 稳住枢纽保留时间通道，使部分因错位而失散的人未来仍有机会得到救援，并阻止当前裂缝继续侵入现实（影响范围需在后续各层提前证明，不能第十层空降）。
4. **两人都是自主选择者：** 苏晚先明确选择保留救援可能，周辰不再替她决定；两人在知道代价后共同选择B。**由周辰主动成为稳定锚点承受玄冰封印**，苏晚虽认可共同责任，仍会在实际裂隙失控时试图抓住他；这不是前面共识自动取消的情感反应。
5. **一人封印、一人被卷走的因果（待审）：** 两种互补本源可能无法在枢纽崩溃时同时维持锚点，两个人的能量位置会反向分配。**这只是解释机制候选，必须在5、7、8层有线索，并在最终剧本里经验证后才能作为规则。**
6. **三百年叙事时间：** 在第一季只呈现“时间代价或不同步警示”，不在此仓库制作未来季剧情，也不要提前武断解释苏晚穿越前后具体有无连续守候三百年，以免与用户原始构思产生冲突。

### 终幕候选镜头节奏（仅剧情设计，非最终15秒执行提示词）
- 巨大时空环停止战斗类音效，周围浮现两条不同命运的无声碎片；极大的空间反而显得安静。
- 周辰、苏晚面对两个都真实的选项，相互说出各自的愿望、恐惧和对失踪者的责任，不能只有系统口播。
- 苏晚主动提出B，周辰主动接下玄冰锚点的禁制；他最后一次认真听取她的意愿，直到禁制启动才转身保护她。
- 玄冰沿真实材质纹路从脚下向上蔓延；苏晚伸手，手指将碰未碰时，被时空裂流卷开。不是靠随机爆炸强行制造悲剧。
- 远景显示小小的人被宏伟枢纽吞没；周辰冰封在原时空，苏晚消失于现代方向的断裂光面。结尾只留下第一季收束与未来命运疑问。

**音乐：** 煽情场景可按《大天蓬》（璐爷版）对应“牺牲/诀别后的情绪”方向设计，但是否实际播放由导演节奏确定；《神话》只在本季少数两人真实浪漫互动的重要场景使用，不能因为最终出现星空就强行播放。商业录音须取得对应授权，未获授权可用原创授权曲替代同类型情绪。

## 六、把剧本落地成1—3分钟/集的生产约束

1. **第一季总集数尚未确定，不在此文自行固定“多少集”。** 后续先做“每层需要多少个戏剧转折”后再确定分集，避免每一层机械分配相同数量的集数。
2. 一集只围绕**一个明确戏剧问题**推进：开头展示危险/疑问，中段一次推进或反转，结尾留下行动或认知悬念；不要为了固定时长空转对白。
3. 每集60—180秒，优先60—150秒；本地MinMaxH3每个生成段≤15秒且只能选实际支持时长。**分集剧本情节节奏可先按镜头事件设计，不能在尚未确认模型档位时随意承诺8秒、12秒等一定可生成。**
4. 每个生成段的“视频提示词.md”必须完整写入**全剧通用正文 + 本集通用状态 + 高质量模板所有适用字段 + 本段具体场景/动作/时间轴 + 声轨和字幕方案**，并配该段真实存在的参考图；禁止只写“沿用母版、见其他文件”。
5. 大场面优先拆成“建立尺度→人物真实反应→机关物理反馈→结果”多个短段，确保角色和空间可控。震撼声场、配音、音乐、字幕可以后期连续跨段混合，不应因为画面是多段生成就让音乐每段重启。
6. 先写第一集60—180秒的完整剧情，再为**每一段**配可真实使用的定妆图、场景图与独立完整提示词，先做一小段实测本地生成画质与声画配合，再逐集推进。
