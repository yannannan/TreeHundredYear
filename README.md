仙侠修仙 × 星际科幻 × 悬疑谜局 × 时空爱情 × 幽默对白。

## 作品设定概览

- 主角：凌渊、苏晚；本源共生，具备不死再生能力。
- 第一季：两人闯上古星际文明遗留的九层星渊塔；隐藏第十层是时空枢纽。第十层抉择最终导致凌渊冰封、苏晚穿越现代。
- 第二季：跨时空、三百年守候、坎坷寻找与错过后重逢，最终二人在现代生活。
- 基调：修仙、科幻、悬疑、人性试炼与爱情相融合；对白有深度且风趣，古今语感融合。
- 制作刚性标准：**15秒为一个视频段落；全剧使用简体中文字幕；每段提示词与该段必需的真实参考素材就近存放。**
- 第二季指定《大天蓬》（璐爷）作为音乐参考方向，公开/商用使用前需核实取得适当授权。
