## 当前第一季设定

- 主角：周辰与苏晚；本源共生、不死可再生，来自上古星际文明的实验。
- 核心舞台：**九层星渊塔**，对外只有九层，实际暗藏加密的第十层「时空枢纽」。
- 闯关包含斗法、逻辑谜题、骗局、人性抉择、科幻机制与幽默深度对白，不允许轻松无代价通关。
- 隐藏第十层：双人本源共鸣、双人活着通关九层、双方拒绝试炼奖励且拒绝离塔后触发；最终选择维持枢纽，周辰陷入玄冰封印，苏晚穿越现代。
- **结尾伏笔**：时空裂隙、三百年等待及命运碎片只用于第一季的悬疑收束，不在本仓库展开未来季剧情。
- **单集成片时长：60—180秒，尽量在60—150秒完成，最长不超过180秒。** 本地MinMaxH3工作流单次生成每段最长15秒（可短于15秒，按实际支持时长设定）。
- **每段完整执行包：**“整部剧通用提示词 + 本集通用提示词 + 高质量分镜模板 + 本段专属情节/时间轴/动作/运镜/配音/音效/配乐”，实际合并到该段独立的 `视频提示词.md`，无需再复制其他文件；本段实际需要的参考图放在同段 `参考素材/`。
- **视听验收目标：**高质量电影级真人画面、按剧情需要呈现震撼巨构/星际/仙侠场景、动作物理合理、周辰和苏晚跨段长相一致，最终成片有角色配音或必要旁白、环境与动作音效、适当配乐、简体中文字幕。声音可由本地工作流或独立配音和后期制作，不虚称一次生成已经具备全部音轨。
- 视觉基准：电影级真人实拍质感、真实人体和物理运动、角色锁定、镜头连续；用户提供的高质量模板作为基础。
