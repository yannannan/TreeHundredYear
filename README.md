## 制作基线

- 只制作第一季及必要续篇埋点，不建立第二季完整剧本或资产。正式剧名、主角周辰/苏晚、九层塔与隐藏十层的已确认设定保持。
- 原始概念：古文明时空试炼设施，真实危险、极难突破。双方共鸣、双方活过九层、双方拒奖拒离塔才开启十层，终局走B。
- 高质量写实仙侠与科幻统一；巨构尺度、人物重心、空间关系与声音反馈服务剧情。允许深度对白、古今混搭、适量粗口、黑色幽默和自然风趣表演，不用无关段子、空喊秘密或爆闪填充时间。
- 每集60—180秒、优先60—150秒；本地MinMaxH3单次≤15秒，档位、分辨率、帧率及声音能力以试片为准。9:16是已定主画幅，不是已确认具体像素尺寸。
- 每个真实段只有一份自包含的视频提示词.md，写齐全剧/本集/本段、分镜、起止状态、配音/音效/BGM、逐句简体字幕原文与时码及真实参考图。字幕不另设文件夹。
