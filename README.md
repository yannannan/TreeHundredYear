# TreeHundredYear｜AI漫剧制作项目

本仓库用于 AI 漫剧的策划、剧本、美术、分镜、提示词、制作素材与成品管理。

## 项目状态

- 阶段：P0 初始化
- 当前已核实的信息：仓库已建立，具体正式剧名、题材、剧集规划、视觉风格尚待确定
- 本仓库所有实际工作以用户确认的创作需求为准；不凭仓库英文名称推断剧情

## 唯一总控／交接文档

**[docs/PROJECT_MASTER.md](docs/PROJECT_MASTER.md)**

此文档集中记录：
- 用户需求与关键决策
- 分集剧本、人物、视觉和制作规范
- 每轮相关对话的摘要、任务、执行进度及下一步
- GitHub 提交与可验收交付物

## 合作与版本管理

每完成一个可验收步骤，就将对应文本和**真实生成的素材文件**提交 GitHub，并更新上述交接文档。用户从仓库拉取结果并验收。无法生成或无法提交的内容必须明确说明，不能用占位素材充数。

> 开始或迁移到新对话时，请先读取 [项目总控与交接文档](docs/PROJECT_MASTER.md)。
