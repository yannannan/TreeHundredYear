# TreeHundredYear｜《我活了300年》双季 AI 漫剧项目

> **第一季**：《我活了 300 年，勇闯九层修仙塔》  
> **第二季**：《我活了 300 年，只为唤醒你》

仙侠修仙 × 星际科幻 × 悬疑谜局 × 时空爱情 × 幽默对白。

## 唯一项目交接文件

**[docs/PROJECT_MASTER.md](docs/PROJECT_MASTER.md)**

所有需求、重要聊天内容、项目总控、创作决策、制作状态和 GitHub 提交历史，一律更新此文件，**不新建第二份交接／工作日志／项目总控 MD**。

## 作品设定概览

- 主角：凌渊、苏晚；本源共生，具备不死再生能力。
- 第一季：两人闯上古星际文明遗留的九层时空塔；隐藏第十层是时空枢纽。第十层抉择最终导致凌渊冰封、苏晚穿越现代。
- 第二季：跨时空、三百年守候、坎坷寻找与错过后重逢，最终二人在现代生活。
- 基调：修仙、科幻、悬疑、人性试炼与爱情相融合；对白有深度且风趣，古今语感融合。
- 制作刚性标准：**15秒为一个视频段落；全剧使用简体中文字幕；每段提示词与该段必需的真实参考素材就近存放。**
- 第二季指定《大天蓬》（璐爷）作为音乐参考方向，公开/商用使用前需核实取得适当授权。

## 制作仓库结构

| 目录 | 用途 |
| --- | --- |
| `docs/PROJECT_MASTER.md` | 唯一项目交接文档、总控和更新日志 |
| `assets/characters/` | 人物设定、定妆、多角度图片（凌渊、苏晚等） |
| `assets/scenes/` | 九层塔、隐藏第十层、现代时空等场景参考图 |
| `assets/props/` | 法器、机关、科技道具、特效参考 |
| `scripts/season01/`、`scripts/season02/` | 每集一个完整剧情 MD，例如 `EP01.md` |
| `episodes/season01/`、`episodes/season02/` | 每集分段制作，按照15秒一个段目录保存完整提示词与参考图 |
| `audio/` | 配音、音乐、音效（仅收录有权使用的素材） |
| `subtitles/` | 简体中文字幕输出文件 |
| `visual/covers/` | 封面、海报及视觉宣传图 |
| `deliveries/` | 可交付的正式成片 |

分段目录结构将在确定剧集后按 `episodes/season01/EP01/SEG001_0000-0015/prompt.md` 与同级 `references/` 内的真实图片素材生成。空文件夹使用 `.gitkeep` 追踪，不代表资产完成。
