## 制作基线

- 塔外2集；前九层依次3/3/3/2/4/4/3/3/2集；隐藏十层3集。按事件分集，不一层一集，也不是旧12篇机械切割。
- 原始概念仍是古文明时空实验/试炼设施，前九层是真实危险的难关，不保证安全。26集共鸣、28集双活体通关、29集各自拒奖拒离，缺一不开放十层。
- 本源再生不等于无限能量、食物与免痛，不恢复所售记忆、不复活凡人。古今混搭、深度对白、适量粗鲁、黑色幽默和风趣表演服务人物，不强塞段子。
- 每集60—180秒，优先60—150秒；当前终集180秒。剧本场次预算不等于生成段；本地MinMaxH3单次≤15秒，实际档位和音画能力须试片。
- 每个段落只有一份自包含“视频提示词.md”，写全整剧+本集+本段、起止状态、连续动作、运镜、配音/音效/音乐和逐句简体字幕时码；真实参考图放同段就近目录，字幕不另建文件夹。
- [全剧通用母版V1.4](剧集制作/第一季/全剧通用提示词.md) · [电影级单段模板V2.1](剧集制作/第一季/15秒高质量电影提示词标准模板.md) · [人物视觉方向提案](人物资产/第一季男女主人物设计提案（待审V1）.md)。
- 以抖音为主，兼顾快手/红果竖屏准备。9:16不是所有发布规格通用的证明；具体渠道以实际入口与试片核验。
