活了三百年却不知来历的周辰，与修物为生、携短刃的苏晚，因塔外时间逆流与木匠沈砚寻女失踪而结伴，进入上古星际文明封装的时空实验设施"九层星渊塔"；真实通关前九层、形成双源稳定共鸣、各自独立拒真奖励与真离塔机会后，打开隐藏第十层"时空枢纽"，知情后共同选择 **B 方案**——周辰冰封作固定锚、苏晚在真实维护时域生活守护三百年，换回十三名被困者回家并归正塔外时间异常；三百年后周辰苏醒，苏晚被随机抛入现代，留下第二季"跨时空寻人"的交界。

## 3. 制作流程与 15 秒提示词规范

### 3.1 制作流水线（全季统一范式）

```
剧本（V3，已完成）→ 资产（人物/场景/道具静态图，已完成）→ 逐段执行文本（313段视频提示词.md，已完成）
→ [实际 H3 视频生成 ❌未开始] → [普通话配音/音乐/音效 ❌未开始] → [字幕渲染/口型 ❌未开始] → [剪辑成片 ❌未开始]
```

- 每集一个"执行包"目录（第01集为 `执行包V2`，其余集为 `执行包V1`），内含：执行清单 .md + 每段一个子目录（`第NN段_标题/`，内含 `视频提示词.md` + 该段就近参考图）。
- 每段《视频提示词.md》**必须自包含**，可直接复制到 MinMaxH3；禁止"接上一段/同上/看总剧本"。

### 3.2 15 秒提示词结构：三级合并 + 单段闭环

⚠️ **术语澄清**：项目文档**没有"五段式"这个官方结构**（研读确认）；实际执行的是**三级合并** + **单段闭环**：

1. **第一级 · 第一季整部剧通用提示词**（`剧集制作/第一季/全剧通用提示词.md`，母版 V2.0）：固定视觉语言与世界观底层规则（电影级真人实拍、写实仙侠+上古星际科技、真实物理、统一调色、人物一致性、简中字幕原则、全季负面约束、声音三模式）。
2. **第二级 · 本集通用提示词**：本集时代/地点/环境、服装版本状态、场景空间、光线天气、特殊道具与试炼规则、对白表演风格、音乐规则——**不另建独立本集 MD**，逐集具体化后嵌入每段。
3. **第三级 · 本段专属提示词**：本段剧情任务、上段结束状态、动作起点→过程→结果、景别/机位/焦段/运镜、0—T 秒时间分镜、对白/声音、本段参考图、本段负面约束。

**最终执行原则（模板原文）**："第一季全局通用提示词 + 本集通用提示词 + 本段专属提示词 = 本段最终可直接复制到 MinMaxH3 的完整提示词"。时间轴常规按 **0—5 / 5—10 / 10—15 三段**分写。

### 3.3 单段闭环的 10 个强制字段（模板"最新单段闭环的强制字段"）

| # | 字段 | 作用与写法要求 |
|---|---|---|
| 1 | 本段前情 | 只说明当前动作需要知道的事实/动机/人物关系；**前情不是让模型重演一遍** |
| 2 | 本段剧情 | 完整自然语言写"谁在什么地方、想做什么、遇到什么、采取什么动作、得到什么结果"，不能只有摄影词 |
| 3 | 在场角色绑定 | A/B 标签固定绑定姓名、脸、服装、位置、朝向、持物、伤势和情绪；无 B 时明确 B 不出镜，不为了 AB 格式加新角色 |
| 4 | 首帧状态和尾帧状态 | 人物/动作/机位/道具/光照环境可衔接；**闭环是本段行动有结果，不是把本集悬念全解决** |
| 5 | 0—15 秒完整时间轴 | 动作、机位、声音同步；优先一个主动作，最多两次有理由切镜 |
| 6 | A/B 对白逐句绑定 | 明确谁说、何时说、看谁、怎样说、谁闭嘴；无对白段写明"无对白/旁白" |
| 7 | 字幕逐句简中原文、入出秒和安全区域 | 同一提示词内写全；配乐/环境/动作声与对白分开入点 |

| 9 | 真实参考文件和用途 | 本段文件夹就近保留实际图片；尚缺参考在制作状态中明示，**禁止给不存在的图编号冒充齐备** |

### 3.5 字幕与配音规则（声音母版 V2.0 / V28）

- **声音三模式，每段只启用一种**：A=无对白无旁白（55 段）；B=明确普通话对白（258 段）；C=仅普通话旁白（0 段）。
- **语言锁定**：仅中国大陆标准普通话（Standard Mandarin Chinese, Mainland China）；简体中文只指字幕书写，不允许模型夹英语/外语。
- **模式 B 写法**：逐句给出说话者、起止秒数、汉字原文、情绪；非说话者保持闭口听者表演；不把 A 台词配给 B。
- **字幕**：逐字规范简体中文，原文+起止时码+安全区（白字细深边、横向中心约高度 72%—82%、每次一条、避开手脚动作）；同段后期合成，**不要求 H3 绘制汉字**；全段无台词时明确"本段不显示字幕"。
- **口型**：只在模型确实能对口型时要求同步；不稳定时"生成干净画面/物件环境音，再按本段同一规格独立普通话配音、口型对齐并混音"。
- **内心句**（如 32-10）：与有声对话同段时，H3 只执行模式 B 有声句，内心句保留原时码作同段后期独立音轨，不让 H3 同时启用模式 C 或为内心句动嘴。
- **不另建字幕文件夹**：所有字幕/介绍卡原文与时码都在同段 `视频提示词.md` 内。
- **人物出场介绍卡**：每集首次出场一次；只写姓名/称谓+身份+已确认年龄/寿命+能力，不写性格/衣着标签，不凭空加门派封号；版式简洁白字细暗描边、轻淡入淡出（实例：周辰卡"周辰｜长生剑修 / 历世三百载｜不死不灭 / 神秘之力｜尚未可知"）。

### 3.6 段间承接规则

- **首帧—尾帧闭环**："本段起点匹配上一段终点，终点留下下一段可拍的物理状态"；尾帧即下段首帧依据（第01段尾帧 → 第02段首帧示例见执行包V2）。
- **同场同场景母图**：相邻同场段使用同一条场景母图，不随机变门窗/地形/车/桌/桩位置；摄影机移动只改变投影位置，不镜像环境。
- **机位惯性**：同镜头只设一种主要运动轨迹；首尾构图可与上/下一段剪辑衔接；不将慢推/拉远/环绕同时叠加。
- **尾帧稳定可剪**：末尾保留稳定可剪尾帧，**禁止自行淡黑/片尾字卡/重新播放本段**。
- **道具连续性**：跨段数量位置一致（第01段锁"第02/03段持同一只碗，不再添第二只"；第03集古符三段式状态、检修绳与塔外探路绳严格区分）。
