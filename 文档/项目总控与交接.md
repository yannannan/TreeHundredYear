### 3.1 每轮相关对话必须更新交接文档

- 在每次涉及本项目的实际对话工作中，更新本文件，尽量保留该轮的需求原文要点、问题、决策、任务、执行情况、产出文件、GitHub提交与下一步。

- 要求记录聊天**要点及行动**；不把未实际发生的工具操作标成已执行。
- 更新仅在当前收到并处理项目对话时进行；不宣称在无会话执行时能够自主后台同步。

### 3.1.1 汇报形式：每轮对话结束必须输出表格进度（2026-10-16新增）

- **用户明确要求**：后续所有本项目工作汇报采用**表格形式**，并且**每一次聊完，最后输出项目进度表**。
- 每轮最终回复可以先简要说明已完成事项、当前交付文件及关键结论，但**回复末尾必须有清晰的 Markdown 进度表**；表格是最后的主要内容，不再在表格后追加其他进度说明。
- 建议固定列头：**编号｜工作模块｜当前状态｜本轮实际完成/变化｜下一步**。列数若因特殊内容需要可以调整，但必须体现事实、真实完成状态和明确待办。
- 表格须区分**已完成、进行中、待审定、未开始**；仅计划或建议不得写作实际完成。必要时追加 GitHub 提交状态、版本和链接作为表格行。
- **唯一交接文档的 GitHub 链接放在最终表格的最后一行**，兼容此前“每次回复末尾附交接 MD 链接”的规则。
- 如本轮没有新增人物图、剧本、视频或真实 GitHub 提交，表格明确说明，不捏造进度、不伪造已交付。
- 不仅阶段性大汇报，普通项目讨论结束也执行上述表格结尾要求。

### 3.2 每个完成的实际制作步骤都提交 GitHub

## 四、第一季创作需求定稿基线（持续按最新需求更新）

### 4.1 第一季剧名、整体基调
- 唯一正式剧名：《我活了 300 年，勇闯九层星渊塔》。
- 剧集类型：仙侠/修仙、科幻、悬疑、冒险、爱情、人性抉择，层层反转、持续制造观众吸引点。
- 对白标准：不是僵硬讲设定，不是纯打怪升级；有思想深度、有生活温度、有风趣滑稽的轻松台词，可古语与现代梗混搭，但不破坏世界观与人物性格。高潮处允许克制而真诚，不强行插入笑话。
- **字幕：简体中文，强制要求。** 应区分可读字幕和生成画面内易错的文字元素，后期添加字幕优先。

### 4.2 第一季：九层星渊塔 + 隐藏第十层
**主角与起点：** 周辰（男主）、苏晚（女主）结伴闯上古遗留的「九层星渊塔」。两人“本源共生、不死可再生”；永生源自上古星际文明进行的「本源实验」，属于科幻背景，不是普通修仙功法。二人会受困、受伤、付出代价，不能因再生能力削弱危险感。

**塔的本质：** 上古星际先民留下的时空试验/试炼设施。外界只知九层，每层是规则独立的小世界：有的偏法术斗法，有的偏逻辑解谜，有的偏骗局陷阱，有的偏人性抉择。规则可随机或变化，但写作时必须给各层可理解、可检验的具体通关约束，避免主角依靠运气一路轻松过关。

**感情推进：** 双人并肩渡劫，冲突与磨难中逐渐信任、相依，期间有误判、挫败、代价与幽默互动，不是速成甜宠；情感和闯关相互推动。

**隐藏机制（刚性设定）：**
1. 对外只有第 1–9 层，绝大多数人认为第九层是终点。
2. **隐藏第十层为加密的「时空枢纽」，不会主动开启。**
3. 开启需同时满足：①周辰与苏晚发生本源共鸣；②二人双双活着完成前九层；③二人**都拒绝领取试炼奖励，并拒绝直接离塔**。满足后才可开启隐藏入口。
4. 第十层没有妖兽与传统斗法；以流光、数据流、破碎时空碎片、平行可能性、前世回忆/未来片段/未发生的命运呈现，围绕抉择展开。
5. 抉择 A：关闭时空枢纽，二人回归原天地平安生活，不再卷入危机，但永久失去接触跨时空力量的机会。
6. 抉择 B：维持枢纽稳定；过载引发保护禁制，周辰被玄冰冰封沉睡，苏晚被时空乱流随机抛入别的时空——**现代**。他们事先通过时间碎片理解分离及“三百年等待”的代价。
7. 实际结局走 B：周辰主动承担封印以稳住濒临崩塌的时空枢纽；苏晚来不及抓住他，被时空裂隙卷走。
8. 第一季收束：周辰封存，苏晚穿越；为第二季接续。**不得将第九层通关直接替代第十层的最终抉择。**

**创作关键问题（留白待后续编剧深化，非新增定稿）：** 枢纽失稳会伤及谁、为什么选择 B 而非 A、为何两人不能同时回去、三百年的不同时间流速怎样对应。需要在后续剧本中埋设线索并自洽，未经用户确认不把推演写成已确定事实。

### 4.3 第一季结局的续篇伏笔（仅作为第一季内容）

- 本仓库**只设计、制作、管理和交付第一季**，不建立第二季大纲、分集剧本、提示词、人物、场景、音频、字幕和视频资料。
- 为第一季的情绪闭环与续篇吸引力保留必要悬念：隐藏第十层时空枢纽、双人本源共鸣、周辰自愿玄冰封印、苏晚跌入现代时空、三百年的时间代价与未来重逢的未知可能。
- 伏笔必须自然融入第一季九层星渊塔与第十层剧情，遵循“前期有线索、中段有误导/反转、结尾有情感兑现与未解之谜”的递进结构，不提前剧透未来季的实际故事。
- 续篇如何解释三百年守候与时空先后顺序，属于第一季结尾需要保持**不矛盾、可扩展**的连续性边界；不在本仓库撰写续篇实际解决方案或现代剧情。
- 此处允许出现“第二季”字样，仅为**第一季剧情伏笔的去向标注**，不是第二季内容资产。

### 4.4 视频/美术制作要求
- 每段视频**单次生成不得超过15秒，可依据本地MinMaxH3工作流所支持档位采用更短时长**，绝不强制补足到15秒。每段提示词独立完整、可直接复制给本地工作流，包含实际目标时长及段内0—T时间轴、场景、角色、造型锁定、运镜、动作表情、对白/旁白、音效、已确定参数和简体中文字幕交付要求。
- 同一个段目录必须保存**该段实际所需的角色参考图/场景图/道具图**；不能要求用户横跨多个路径手工猜测哪张可用。可以在段目录下放就近素材副本或使用经过验证的相对路径映射并提供复制用素材包；用户当前要求“段文件夹必须有对应素材”，故优先将参考图实体放入该段 `参考素材/` 中文文件夹。
- 每位主角有独立人设及素材目录，保存人物性格、外貌/服装/武器/能力设定、正面/侧面/背面、全身/半身/特写、主要表情、不同角度参考图；可合并为一张可辨识的**多角度角色说明图**，并保存生成提示词与版本来源。保持跨集稳定性。
- 场景需有独立资产，覆盖第一季九层星渊塔各层、隐藏第十层、第一季结尾时空异象及关键道具；如第一季结尾出现现代时空的短暂镜头，该镜头素材归属于第一季，不另设第二季资产。
- **真实生成、修改、选用的图片及素材必须及时提交 GitHub**，不得把占位图伪装成已完成的参考图。
- **单集成片60—180秒（优先60—150秒）已确定**；第一季总集数、角色定妆、画幅、发布渠道、配音工具/音色仍待确定。最终需要人物配音与音效配乐，但能否由MinMaxH3直接生成声音尚未验证。

### 4.5 第一季情感戏音乐与声画设计（用户最新指定）

**音乐一：《大天蓬》—璐爷演唱版。** 用于关键情感场景**前后**的配乐或歌曲氛围：例如人物深情凝望、相互守护、诀别/玄冰封印时的悲壮感，以及高潮后的余韵。不再将它误写为某个续篇开场的专属歌曲；它服务第一季实际情感场景与情绪曲线。

**音乐二：《神话》。** 用户最新明确：**通常只在周辰与苏晚两人在一起、确有浪漫爱情互动的少数重要场景中择机使用，不能频繁出现。** 时空或星际只是可能增强浪漫气氛的场景，并**不是必备触发条件**；不能因为出现星空、时空画面、二人普通同框或一般对话就播放。避免在相邻、相似的浪漫镜头反复使用，以保留情绪爆发的稀缺性。当前只知道歌名，**演唱者与具体录音版本待用户确认**，不擅自指定艺人或声源。不得借此制作第二季内容。

**后续音乐规划：** 用户表示今后还会继续提供更多音乐参考。所有新增音乐按**歌曲及版本—情感类型—适用戏剧场景—出现频率—禁用/回避场景—授权状态**分类记录，遵循少而精、情绪递进、避免单曲滥用的原则；本仓库仅纳入服务第一季的音乐方案，不预填未提供的歌名。

**制作执行要求：**
- 按剧情划分为“情感铺垫→自然对白→情绪爆发/浪漫高潮→音乐尾奏”层次；在人物说话时控制背景音乐响度，避免人声打架。
- 音乐的使用时点可以跨越多个不超过15秒的视频段，通过剪辑/后期拼接维持音乐连续性；不要强迫每个视频段从头重新播放歌曲。
- 区分角色配音（对白、旁白）与歌曲/背景配乐（BGM）；最终成片的简体中文字幕仍要覆盖准确的对白，若实际使用歌曲歌词还须核实相关授权及字幕同步。
- 以上只是**用户指定歌曲的情绪与选曲方向**，不意味着已经取得歌曲原录音或词曲的公开发布、剪辑、商业使用权；在确认授权之前，不向 GitHub 上传原曲，不擅自把商业歌曲直接用于发行成片，可以使用合法授权或原创同情绪音乐。

### 4.6｜视频提示词必须“每段自包含”，采用三级通用结构

用户确认前置制作要求：**每一集、每一段都必须有通用提示词参与生成。**

为兼顾维护与实际复制执行，采用：
1. **第一季全局通用提示词**：统一电影级真人实拍、写实仙侠+上古星际科技、真实人体与物理、摄影语言、人物一致性、字幕及全局负面约束。
2. **本集通用提示词**：统一本集时代、场景、人物当前服装/状态、光线、试炼规则、声音和本集特殊视觉条件。
3. **本段专属提示词**：本段≤15秒的剧情任务、上一段结束状态、动作起点→过程→结果、运镜、时间轴、对白/旁白/音效/配乐、参考图和特殊约束。

**最终交给MinMaxH3执行的每一个“视频提示词.md”必须把上述需要的通用内容与本段内容合并成一条完整提示词。** 不能写“同上”“沿用上一段”“参考本集通用提示词”后让模型依赖其他文件。原因是各视频段独立生成，模型不能假设拥有上一段文本上下文。

文件可以分层维护，但最终段目录必须自包含：
- `剧集制作/第一季/第01集/00-本集通用提示词.md`
- `剧集制作/第一季/第01集/第001段_.../视频提示词.md`（保存合并后的最终版本）
- 段目录的 `参考素材/` 保存该段真实使用的参考图。

**注意：** “通用”不等于所有段落机械复制完全相同。人物服装、伤势、场景、时间、光线、道具等因剧情发生变化时，必须更新相应内容；但仍然要在该段最终提示词里明确当前真实状态。

### 4.7 第一季制作最新硬标准：周辰、1—3分钟、高质量震撼声画

**最新确认：** 男主为**周辰**、女主为**苏晚**；原男主“凌渊”是旧版本称呼，第一季故事、九层试炼、隐藏第十层的开启条件和玄冰封印结局均不改变。

**单集与分段时长：** 每集最终完整成片**60—180秒（1—3分钟）**，在剧情足够完整的前提下**优先60—150秒**，硬上限**180秒**。每个本地MinMaxH3视频生成段最长15秒，可更短，必须选择真实工作流支持的时长档位。逐段时间码连续，总成片时长包含实际片头、转场、结尾剪辑；超过180秒必须调整结构而非强行超标。

**每段提示词绝对不可省略：** 一段的最终 `视频提示词.md` 必须实际写入**全剧通用提示词 + 本集通用提示词 + 高质量电影级模板要素 + 当前段具体剧情/运镜/动作/时间分镜/对白/配音声线/音效/配乐/字幕/实存参考图**。一段一条完整、自包含、可复制用于该段视频生成的提示词，严禁只写“同上”“引用全剧母版”或依赖上一段对话。

**全剧通用母版真实落库：** `剧集制作/第一季/全剧通用提示词.md`；视频高质量标准模板：`剧集制作/第一季/15秒高质量电影提示词标准模板.md`。逐集维护本集通用条件，不创建第二份交接文件。

**场景质量与震撼：** 电影级真人实拍、高级光影、人物真实表演与面部一致、东方修仙×星际科技统一美术；宏大场景采用空间尺度、建筑物理、远近透视、体积光、颗粒尘埃和声场联动产生震撼感。并非每段都要轰炸特效，静谧爱情戏与轻松戏仍需真实、精美、有节奏。

**配音与音画：** 每个段落必须写出人物对白/必要旁白配音的角色、声线、语速、情绪、时间点和实际需要的环境声、动作音效、背景音乐与简体中文字幕方案。允许没有对白的纯视觉段，但要明确环境音效/配乐/有目的的静默。**最终成片必须有完整配音及音效混音**；如本地视频模型不能同步产出准确中文声音、口型、字幕，则由单独配音/音频制作及字幕后期完成，不夸称单条提示词必然一次出片带声。音乐仍遵守《大天蓬》情感前后、《神话》重要浪漫场景低频使用及授权规则。
