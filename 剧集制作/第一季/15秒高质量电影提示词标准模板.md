# 第一季｜单段最长15秒电影级真人实拍视频提示词标准模板（制作规范 V1.4）

> 作品：《我活了 300 年，勇闯九层星渊塔》  
> **适用范围：仅第一季。** 此文件是可复用制作模板，不是额外的交接文档。每集每段在其段目录保存填写完成的 `视频提示词.md` 与本段实际参考图。
> 原则：使用用户指定的**本地 MinMaxH3 视频生成工作流**，每段视频的**计划生成时长不得超过15秒**，不是每段必须生成15秒。具体可用档位以实际本地工作流为准；严格控制故事事件密度、生成成本和可执行动作；镜头清晰且前后可剪辑衔接。电影质感不是“堆叠形容词”，而是角色参考、场景空间、光照、具体动作与摄影计划互相一致的结果。

## 一、核心改进（相对用户初始模板）

1. **15秒是单段时长上限，而非每段固定时长。** 根据本段内容复杂度和本地工作流实际支持的时长选择，例如实际可用时选择较短片段或最长15秒片段；无须为了凑满15秒加入无关动作。一段建议以一个稳定连续镜头为主，必要时合理切镜；模型不支持多镜头时分开生成后剪辑，不强迫单次生成复杂切镜。
2. **角色一致性优先于华丽镜头词。** 固定主角正/侧面图、面部特征、发冠/发型、服装版本、佩饰及伤势状态。角色图片与场景图片在同段 `参考素材/` 提供，明确其用途和优先级；没有真实图时标记待生成，禁止引用不存在的图。
3. **动作遵守因果和物理逻辑。** 给出每5秒的主动作、起始姿态/最终姿态、动作方向、人与物的空间关系、道具的连续性，避免凭空位移或动作重置。
4. **摄影机要服务叙事。** 同镜头只设一种主要运动轨迹和合理焦段，优先清晰可复现；慢推与追拍不能同时冲突指定，避免“手持 + 完全静稳”矛盾。
5. **声音与字幕拆层。** 对白、旁白、环境声、动作声、配乐分别写；若视频引擎不支持稳定口型/中文字幕，视频层可纯净无字生成，后期按台词添加**简体中文字幕**，而非省略字幕。
6. **写续篇钩子但不写续篇制作。** 允许第一季该段的“玄冰纹样、星际编码、三百年倒计时、未来城市碎片”等线索（仅在剧情里确有必要时），不得预先制造第二季完整场景或人物情节。
7. **参数与能力对应。** 画幅、分辨率、帧率、随机种子、参考图数量需按实际使用的 AI 视频工具支持填写；提示词无法独自保证真4K、锁脸、精确口型及精确字形，后期增强与人工审核不可替代。
8. **画面约束以实际失败风险排序。** 首重人物一致、肢体正确、场景拓扑不变、行为因果连续，其次抑制伪CG质感、漂浮道具、过度闪烁、杂乱光影；负面词不可自相矛盾。

## 三、每段交付前的自检标准

| 维度 | 必须通过的检查 |
| --- | --- |
| 时长合规 | 每段实际生成时长 ≤15秒且属于本地工作流支持档位；分镜0—T秒完整闭合，不缺秒、不超载，动作有起因结果 |
| 故事连续 | 本段起点匹配上一段终点，终点留下下一段可拍的物理状态 |
| 画面一致 | 人物固定外貌/服装/伤势，道具数量和场景结构前后一致 |
| 镜头语言 | 摄影轨迹合理，无同一镜头冲突性指令，主体始终明确 |
| 表演与台词 | 台词能在本段实际时长内自然说完；幽默符合角色与戏剧情境，重要转折不滥用笑话 |
| 场景物理 | 光线、材质、接触反应和人物重心真实；科幻法术反馈能被观众理解 |
| 素材完整 | 实际存在所引用的对应角色、场景、道具参考图，图在本段可直接取得 |
| 字幕与音频 | 最终成片使用简体中文字幕；音效与可见动作对应 |
| 叙事埋点 | 只用当前剧情有依据的第一季伏笔，不预先生成续篇成片或内容 |
| 可落地性 | 输出设置匹配实际视频引擎能力，后期处理与模型内生成分工明确 |

## 四、本地 MinMaxH3 时长与生成执行规则

- 本地 MinMaxH3 是当前用户指定的视频制作工作流；以**用户实际运行的本地工作流及其可用时长档位**为准，不凭模板认定任意秒数都可用。
- **硬上限：每个单次生成视频段 ≤15秒。** 可以更短，取决于模型/节点档位、剧情密度、显存与稳定性。不用为凑满15秒硬拉长镜头。
- 每集总时长不受单段15秒上限限制：将多个真实生成的片段顺序剪辑，分段时间轴累计连续；若单段任务大于15秒必须拆段。
- 起止时间和文件夹名必须与**实际生成时长**对应；本段专属完整提示词及必要真实参考图同目录存放。
- 面向较重场景（多人复杂走位、强特效、频繁转换视角）优先拆成内容更简单的短段，避免为了片长而明显降低运动质量或角色一致性。
- 生成画面难以精确显示中文时先做无字画面，后期合成简体中文字幕，最终成片必须具备字幕。
- 本地生成时间、分辨率、输出帧数、帧率、采样和显存设置由实际工作流决定，未测试的数值不能写作确定配置。

## 四、文件组织规范

- 剧集完整剧情：`完整剧本/第一季/第01集.md`。
- 第一集第一段：`剧集制作/第一季/第01集/第001段_00分00秒-00分10秒/视频提示词.md`（仅为10秒举例，实际需选用本地工作流支持的时长；如果选择15秒则段尾改为00分15秒）。
- 上述示例本段真实参考图放：`剧集制作/第一季/第01集/第001段_00分00秒-00分10秒/参考素材/`；下一段起始时间紧接本段结束时间，依照真实时长递增。
- 人物主资产长期保存于 `人物资产/凌渊/`、`人物资产/苏晚/`，并将该段需要的具体图放到本段 `参考素材/` 内，避免交付时人工跨路径查找。
- **不提前建立空剧集/空段假充完成作品**；模型无法做到的配置用显式“后期完成”说明。
