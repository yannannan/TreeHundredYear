# 九层星渊塔资产｜第一季统一固定资产库

> 本目录是《我活了300年，勇闯九层星渊塔》第一季所有剧集共同引用的塔体与塔内空间视觉资产库。九层星渊塔属于贯穿全季的核心固定场景资产，不归属于某一集；任何单集不得擅自重新设计塔体轮廓、九层结构、星环、塔基或既定楼层空间。

## 资产管理原则

1. **唯一视觉母体**：先建立整座塔的总外观、结构比例和外部环境母设定，再建立塔基、入口、内部空间和各层资产。后续各集从本目录引用，不另造一座风格不一致的塔。
2. **先外后内、先总后分**：塔体整体外观 → 塔外环境 → 塔基与入口 → 内部九层总体结构 → 每一层独立空间 → 关键局部与镜头资产 → 单集场景调用。
3. **概念与正式资产分开**：提示词草案、测试图、用户确认图、正式母图分别标记状态；未经用户验收的图不得标为正式资产。
4. **剧本规则优先**：每层物理法则、剧情功能和人物代价以《第一季剧情总规划》为准；美术不得擅自改变剧情机制。
5. **跨集连续性**：塔体轮廓、九层层级、星环数量与相对位置、塔身材质、塔基构造、外部山脉和云海关系等一经用户确认，后续镜头必须沿用。
6. **隐藏第十层保密**：第十层《时空枢纽》属于隐藏设定，单独隔离管理；前期外观和内部资产不得提前暴露其完整真相。

## 设计与生产顺序

- 阶段A：整座九层星渊塔外观母设定（超远景、正视、侧视、三分之四视角、俯视结构）。
- 阶段B：塔外环境母设定（山脉/雪域/云海/天象/地貌/光照关系），确定塔与地理空间的真实连接。
- 阶段C：塔基、入口、外部道路、桥梁、平台、门体和尺度参照。
- 阶段D：塔内九层总体结构与空间关系。
- 阶段E：逐层建立独立空间母图、关键地标、材质、光影、物理法则可视化及通行结构。
- 阶段F：关键结构细节、统一提示词、分镜调用模板与验收记录。
- 阶段G：单集场景制作时引用已验收的塔体/楼层母资产，不反向随意改变母设定。

## 关键视觉设计检查项

塔体层级必须清晰可辨；塔顶与星环的尺寸、距离、倾斜和压迫关系必须有统一比例；云团应自然随机且有空间层次，不能规律复制；塔基必须与山体/地貌形成可信承重连接；天空背景要服务塔体尺度而非喧宾夺主；光源方向、雾气、逆光和材质反射必须统一。上述为设计检查维度，具体造型数值待母图方案确定。

## 开场场景状态

第一集开场“苏星瑶守望冰封周辰”的具体地理位置与冰封设施尚待重新设计。雪山之巅、上古山洞/遗迹、塔内某层冰封禁地等均是候选方向，**尚未确认任何一个为正式场景**。必须先完成塔体外观、塔外环境和楼层空间设计，再结合剧情因果确定开场场景；此前测试图不作为正式场景母图。

## 统一视觉风格（新增强制标准）

九层星渊塔及其外部环境、塔基、入口、内部九层场景，全部采用**真人电影级写实视觉**。核心气质为：**巨物感、震撼感、上古科技感**。画面必须让人相信这座巨构真实存在于一个有地质、空气、重力、光照和文明历史的世界中。

- **真人电影级**：真实摄影机成像逻辑、真实镜头透视、自然景深、物理可信的光影、体积雾、空气透视、材质微观细节；建筑、山体、云层和人物之间有可信的空间关系。
- **巨物感**：用山脉、峡谷、云层、古桥、道路、极小的人物或队伍作尺度参照；强调塔体高度、厚度、重量、纵深和对环境的支配感。
- **震撼感**：采用有明确视觉中心的史诗级构图，利用低机位仰视、超远景、真实视差和前中后景层次表现规模，不依赖无节制的发光特效。
- **上古科技感**：东方古代巨构与失落星际文明技术融为一体，科技结构必须像建筑本身的承重、能源、交通或运行系统，而不是后贴的霓虹灯、科幻UI或游戏装饰。
- **参考图使用**：此前已生成的塔体图片可以作为提示词的视觉参考，用于提取构图气势、塔体轮廓方向、星环关系、雾云层次和色彩氛围；在用户正式确认前，不把测试图当作最终结构标准，不照搬其中可能错误的比例或构件。
- **跨层统一**：塔外、塔内九层和关键细节都必须保持真人电影级材质与真实空间尺度；各层可有不同物理法则和美术主题，但必须看得出属于同一上古文明系统。

禁止方向：动漫、插画、游戏CG、手游场景、塑料质感3D模型、廉价渲染、概念草图感、漂浮贴图式建筑、无承重逻辑的结构、过度霓虹、满屏魔法光效、无意义粒子、重复云团、过度锐化和虚假HDR。
