# 06｜生成提示词与验收记录

集中保存九层星渊塔的统一母提示词、外观各角度提示词、环境提示词、楼层提示词、负面约束、模型/工作流参数、生成批次、验收意见、修订历史和正式资产登记。

## 提示词职责分层

- 塔体统一提示词：只写所有塔体镜头共同不变的结构、材质、文明语言和比例锚点。
- 外观角度提示词：只写相机角度、焦段、景别、构图、可见面和当前镜头任务。
- 楼层统一提示词：只写本层跨镜头不变的空间结构和法则表现。
- 单镜头提示词：只写镜头独有的动作、位置、天气、光照变化和剧情状态。

## 验收门槛

塔体层级准确、星环关系一致、空间有真实体积、塔基/地形连接可信、云层随机自然、天空与光照有逻辑、材质真实、无无故增减构件。用户确认前状态一律为待验收。
