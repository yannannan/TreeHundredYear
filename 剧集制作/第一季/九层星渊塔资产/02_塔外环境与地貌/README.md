# 02｜塔外环境与地貌

本目录建立九层星渊塔固定的地理环境母设定，确保跨集出现时塔与山河、云海和天空的关系一致。

## 需要设计的内容

- 塔所在的地理位置与整体地貌关系。
- 山脉/雪域/断崖/峡谷/云海的远中近层次。
- 塔基与山体、地面或深渊之间的承重连接。
- 天空、云团、雾气、天气、时间和光照基准。
- 人物、山体、桥梁等尺度参照物。
- 从不同方向观看整塔时，地形和塔体的连续关系。

## 设计约束

环境不能只是漂亮背景图。必须解释塔如何真实立于、嵌入、跨越或连接地貌；云雾不得吞没塔体识别特征；不同天气版本必须保持地形轮廓不变。

## 当前状态

地理位置与环境风貌待整体外观方案出来后共同确定。雪山、云海、山脉等为候选元素，尚未定为唯一场景。
