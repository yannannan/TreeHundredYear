# 01｜塔体整体外观

本目录只管理九层星渊塔本体的固定外观，不管理某一集的具体剧情场景。

## 必须建立的正式资产

1. 整塔超远景母图：完整九层塔体、塔顶星环、塔基和周边尺度关系。
2. 正向远景母图：清晰展示九层结构和塔顶关系。
3. 三分之四视角母图：展示塔体真实厚度与空间结构。
4. 侧视母图：检查塔体外轮廓、层级进退和环体纵深。
5. 高空俯视母图：检查塔顶、星环轨道和塔身结构。
6. 塔基仰视母图：建立巨物尺度和压迫感。
7. 塔顶星环局部、塔身层级连接、材质与纹样局部图。

每个角度独立出图。禁止将20角度人物资产工作流的拼图方式套用到塔体母图；如需多视角参考，必须确认每格都是同一塔体的准确结构，最终仍分别保存单角度正式图。
