# 01｜塔体整体外观

本目录只管理九层星渊塔本体的固定外观，不管理某一集的具体剧情场景。

## 必须建立的正式资产

1. 整塔超远景母图：完整九层塔体、塔顶星环、塔基和周边尺度关系。
2. 正向远景母图：清晰展示九层结构和塔顶关系。
3. 三分之四视角母图：展示塔体真实厚度与空间结构。
4. 侧视母图：检查塔体外轮廓、层级进退和环体纵深。
5. 高空俯视母图：检查塔顶、星环轨道和塔身结构。
6. 塔基仰视母图：建立巨物尺度和压迫感。
7. 塔顶星环局部、塔身层级连接、材质与纹样局部图。

每个角度独立出图。禁止将20角度人物资产工作流的拼图方式套用到塔体母图；如需多视角参考，必须确认每格都是同一塔体的准确结构，最终仍分别保存单角度正式图。

## 当前状态

待设计。塔身比例、层级外轮廓、星环数量/尺寸/倾角、塔顶构件、主材质及纹样尚未正式定稿。


## 外观提示词的强制风格要求

所有整塔外观图必须达到真人电影级写实。画面要体现真实摄影机拍摄到的上古文明超级巨构，而非游戏概念图。以山脉、云海、峡谷、古桥或微小人物建立尺度参照，突出塔体对环境的巨大压迫；塔身必须有真实厚度、承重、材质磨损和结构连接。星环与塔顶必须具有明确空间关系和可信的巨型工程结构。上古科技元素应融入塔体建筑和运行结构，避免霓虹装饰化。

此前生成的塔体图片可作为提示词参考，重点参考构图气势、塔体轮廓方向、星环关系、云雾层次与色彩氛围；其中的比例和结构细节仍需重新审定，未经用户确认不得直接当作正式母版。

**外观图负面约束**：动漫、插画、游戏CG、手游宣传图、塑料3D模型、低成本渲染、漂浮贴图、无承重结构、星环随机悬浮、九层结构不清、过量霓虹、无意义魔法光效、云层重复复制、塔体被雾气完全遮挡、虚假HDR、过度锐化。
