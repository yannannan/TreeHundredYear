# 04｜塔内空间与楼层

九层星渊塔内部不是九间普通房间，而是九个拥有独立尺度、地貌/结构、物理法则和剧情试炼的巨型空间世界。每层必须有自己的空间母图，同时与塔体母结构保持连接关系。

## 每层资产统一交付项

1. 本层空间超远景母图。
2. 本层主空间正向/侧向/俯视结构参考图（各角度单独生成）。
3. 本层入口与离开通道。
4. 核心地标与关键构筑物。
5. 本层物理法则可视化资产。
6. 材质、纹样、光照、天气/粒子和环境声线索。
7. 人物尺度参照与镜头可用区域。
8. 本层跨集连续性说明、正负提示词和验收记录。
