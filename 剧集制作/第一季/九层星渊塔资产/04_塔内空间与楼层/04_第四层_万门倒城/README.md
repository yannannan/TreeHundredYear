# 第四层《万门倒城》

- 对应集数：第09—12集
- 剧情空间法则：每一道门显影人物曾经可作出的选择，形成可接触的分岔现实；进入其一会使其他路径关闭。
- 视觉资产状态：待设计、待用户验收；本目录当前只建立归档位置，不代表已生成正式场景图。

## 必须制作

- 本层空间超远景母图。
- 主轴/侧向/俯视结构参考（单角度独立图）。
- 入口、出口与连接上一层/下一层的过渡空间。
- 核心地标、危险机制和物理法则可视化。
- 材质、光影、雾气/粒子、尺度参照和镜头区域。
- 本层统一提示词、节点/镜头专属提示词、负面约束、验收记录。

## 连续性要求

本层所有集数共用同一空间母体。可以随剧情改变破损、能量状态、天气和人物活动，但不能改变未经确认的基础空间结构。
