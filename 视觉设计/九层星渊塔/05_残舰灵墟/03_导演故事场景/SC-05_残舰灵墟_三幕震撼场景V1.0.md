# 第05关《残舰灵墟》｜三幕震撼场景资产 V1.0

**状态**：导演场景草案，尚非整集完整剧本。**九层闯关，不是一关一集。**

**关卡主题**：星际遗迹｜本源实验真相。

## SC-05-A 建立场景
破碎星舰从虚空浮现，与古老仙殿接合。使用人物和多层结构的真实比例尺；镜头需让观众一眼辨认危险与空间范围。

## SC-05-B 机关升级
失控的航行装置扭曲走廊、方向与重力。机关必须有物理或规则原因、角色反应和实际后果，不采用无因闪爆。

## SC-05-C 高潮闯关
闯过重启的舰核，获得生命本源秘密的一条线索。本条仅为创意方向，具体关卡破解方式需要编剧与用户正式验收。
