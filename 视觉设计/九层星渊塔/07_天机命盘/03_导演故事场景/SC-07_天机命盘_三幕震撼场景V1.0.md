# 第07关《天机命盘》｜三幕震撼场景资产 V1.0

**状态**：导演场景草案，尚非整集完整剧本。**九层闯关，不是一关一集。**

**关卡主题**：未来预测｜命运选择。

## SC-07-A 建立场景
横贯苍穹的巨大命盘升起，发出成千上万条光路。使用人物和多层结构的真实比例尺；镜头需让观众一眼辨认危险与空间范围。

## SC-07-B 机关升级
每预见一次未来，另一条可选道路就崩塌。机关必须有物理或规则原因、角色反应和实际后果，不采用无因闪爆。

## SC-07-C 高潮闯关
面对不确定未来仍选择承担行动与代价。本条仅为创意方向，具体关卡破解方式需要编剧与用户正式验收。
